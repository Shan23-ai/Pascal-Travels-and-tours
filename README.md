# Travel Agency Website

A polished, modern travel and visa services website showcasing destinations, travel visas, work visas, study visas, Canada PR pathways, and East Africa tours. The project is designed as a professional landing experience with a strong visual identity and clear service presentation.

## Highlights

- Travel visas for major destinations
- Work and study visa support
- Canada PR and immigration pathways
- East Africa safari and beach tour packages
- Clean, modern interface for a premium travel brand

## Project Structure

- index.html — main landing page
- style.css — visual design and layout
- app.js — interactive site behavior
- data/packages.js — core service and package data

## Launch locally

Open index.html in a browser, or use a simple static server if preferred.
